# Stock Analysis Dashboard

## Project Overview
This project is an advanced quantitative stock analysis application designed to predict stock prices utilizing natural language processing (NLP) on historical corporate filings. It relies on both numerical data (historical pricing, revenue growth, net margin) and qualitative sentiment extracted from the Management's Discussion and Analysis (MD&A) sections of SEC 10-Q statements. The project features a backend data processing pipeline that can run headlessly or from a web interface, robust walk-forward cross-validation, Bayesian hyperparameter tuning using Optuna, and interactive backtesting visualizations in a Streamlit dashboard. 

## Project Structure

### Root Directory
- **`app.py`**: The main entry point for the Streamlit frontend dashboard. It configures the high-level application layout, navigation sidebar, and acts as the welcome screen that introduces users to the application.
- **`main.py`**: The CLI entry point for executing the backend pipeline. It accepts command-line arguments (like `--fetch`, `--process`, `--engineer`) to sequentially download SEC reports, process language sentiment, train machine learning models, and simulate past portfolio performance.
- **`pyproject.toml` / `uv.lock`**: Configuration files used by the UV package manager to manage the project's Python dependencies. They ensure that all external libraries (like `streamlit`, `xgboost`, `optuna`, `transformers`) are strictly version-controlled to maintain a stable environment.

### Source Code (`src/`)
- **`src/config.py`**: Centralizes all configuration constants across the application. It stores API keys, file caching paths, list of tracked tickers, default machine learning hyperparameters, and EDGAR authentication settings to ensure single-source-of-truth configuration.
- **`src/data_loader.py`**: Responsible for the foundational data acquisition steps. It fetches raw 10-Q corporate filings directly from the SEC EDGAR database using the `edgar` library, and also pulls historical daily stock price changes via the `yfinance` library.
- **`src/processor.py`**: Extracts sentiment and quantitative scores from the unstructured textual data in MD&A sections. It features a dual-pipeline routing system that lets users choose between OpenAI's `gpt-4o-mini` API or a local, leak-free HuggingFace `ProsusAI/finbert` model.
- **`src/feature_eng.py`**: Calculates the mathematical features needed by the predictive model. It computes quarter-over-quarter revenue growth, net profit margins, shifts in corporate sentiment, and the forward-looking 90-day stock returns used as the training target.
- **`src/model.py`**: Houses the core machine learning logic using the `xgboost` framework. It conducts walk-forward cross-validation to prevent look-ahead bias and utilizes `optuna` for automated Bayesian hyperparameter tuning to minimize prediction errors.
- **`src/backtester.py`**: Evaluates the real-world profitability of the model's predictions. It simulates a trading portfolio over historical quarters, investing proportional capital into stocks predicted to have positive returns, and calculates resulting quarterly portfolio values.

### Streamlit UI (`pages/`)
- **`pages/1_Data_Pipeline.py`**: Provides a graphical interface for running the OpenAI-driven sentiment pipeline. It allows users to download new SEC reports, run the GPT-4o-mini text extraction, and compute engineered features without touching the command line.
- **`pages/3_Data_Pipeline_Finbert.py`**: An alternative interface specifically for running the leak-free, local FinBERT data pipeline. It ensures historical sentiment extraction relies on a static pre-2020 model to guarantee institutional-grade backtesting without prior knowledge bias.
- **`pages/2_Strategy_Lab.py`**: An interactive sandbox for portfolio simulation and results visualization. Users can manipulate model parameters, toggle Optuna tuning, and immediately compare the resulting equity curve against the S&P 500 benchmark.
- **`pages/4_Recommendations.py`**: Forecasts future stock movements based on the latest available, unseen quarterly data. It highlights the strongest current buys generated by the model for practical trading application.
